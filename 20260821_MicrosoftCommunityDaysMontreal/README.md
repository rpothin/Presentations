## AI-Native Power Platform Development: Building from the IDE

### Abstract

For years, building on Power Platform meant opening a browser, navigating the maker portal, and clicking through screens to manage Dataverse, create apps or configure agents. That experience is genuinely valuable, but if you come from a developer background, it can feel a little disconnected from your usual tools and workflows.

Over the past few months, Microsoft has been shipping a new generation of Skills that extend your AI coding agent with deep Power Platform awareness - and they change that dynamic entirely. In this session, we explore three areas where this shift is already taking shape:

- **Dataverse** - query tables, explore data models, and create records through natural language, without leaving your IDE.
- **Power Apps code apps** - scaffold and deploy a React-based application with a prompt, from first file to running app.
- **Copilot Studio agents** - lead an agent in authoring, testing, and publishing an agent.

The session follows one exploratory journey through the retained AI coding sessions and artifacts behind a fictional Poutine League solution. The focus is not only on productivity gains, but also on the boundaries that remain important: solution membership, generated files, publishing, ALM, governance, review, and operational responsibility.
